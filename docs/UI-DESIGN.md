# 界面设计规范

本文是 FreeType 界面的对齐基准。改动设置窗口的布局、颜色、字号、间距或组件前，先读本文；新界面按本文取值，不另起一套。规则与代码不一致时，先确认哪一边是对的，再同时改代码和本文。

## 范围

| 界面 | 代码位置 | 适用方式 |
| --- | --- | --- |
| 设置窗口（含弹窗、搜索、统计） | `windows/app` | 全部按本文执行 |
| 候选窗、整句编辑区、候选右键菜单 | `windows/tsf/src/ui` | 尺寸与定位锁定，见「锁定界面」；只按本文核对配色可读性 |
| 悬浮状态栏、状态提示 | `windows/server/src/desktop.rs` | 同上 |
| 托盘菜单、任务栏「中 / 英」按钮 | 系统原生菜单与图标 | 跟随 Windows，不自绘 |

打字时出现的界面（候选窗、编辑区、状态栏、提示）以打字流畅为先：它们的位置、尺寸、排版和交互不因本文的视觉调整而改变，也不得让按键应答变慢、候选窗迟出或闪烁。

## 原则

1. 层级靠字号、字重、间距和对齐表达，不靠边框、阴影、底色块或解释文字。
2. 中性色占绝大部分面积；品牌粉是唯一强调色，只标出「已选中」、主操作和关键数据。
3. 一层分组：页面上是分组面板，面板里只有行和细线；面板里不再套面板、卡片或带底色的框。
4. 留白宁多勿少；所有间距取 4 的倍数。
5. 文字只写操作需要的信息：默认值、前提、限制、风险和后果。不写标语、副标题和复述标题的说明。

## 设计令牌

令牌定义在 `windows/app/widgets.go` 顶部。代码里不写散落的数字和颜色；需要新值时先加令牌并更新本表。

### 颜色

| 用途 | 令牌 | 浅色 | 深色 |
| --- | --- | --- | --- |
| 页面底色（侧边栏和内容区） | `palette.page` | `#f5f5f7` | `#161618` |
| 侧边栏悬停 | `palette.pageHover` | `#ececf0` | `#222226` |
| 侧边栏选中 | `palette.chosen` | `#e6e6ea` | `#2e2e33` |
| 分组面板 | `palette.card` | `#ffffff` | `#222225` |
| 面板内悬停（搜索结果等可点行） | `palette.cardHover` | `#f5f5f7` | `#2a2a2e` |
| 分隔线、小框边 | `palette.border` | `#dedee2` | `#36363b` |
| 主文字 | `palette.text` | `#181818` | `#f2f2f2` |
| 次要文字 | `palette.muted` | `#6a6a6a` | `#a3a3a3` |
| 键帽、标签底色 | `palette.subtle` | `#f2f2f4` | `#2c2c30` |
| 控件面（按钮、输入框） | `Theme.Surface` | `#f2f2f4` | `#2c2c30` |
| 控件边框 | `Theme.Border` | `#cfcfd4` | `#4a4a50` |
| 焦点环 | `Theme.Focus` | `#3f3f46` | `#d4d4d8` |
| 强调色 | `brandPink` | `#ffb3fa` | `#ffb3fa` |
| 强调色上的文字 | `inkOnPink` | `#18181b` | `#18181b` |

- 强调色用于：开关打开、复选框勾选、主按钮（`ui.PrimaryButton`）、统计图的数据。一个操作区最多一个主按钮。
- 焦点环用中性深灰，与「已选中」的粉色分开。
- 错误、成功沿用 mygo 主题的 `Danger`、`Success`，只用于文字和图标，不画彩色状态点。
- 统计图只用强调色的深浅：最重要的数据用最深一级，其余依次变浅，再接 `muted`、`border` 灰（`statsAccent`、`statsShades`，色阶来自 `keyboardHeatColors`）。
- 高对比度模式下不使用以上颜色，全部跟随系统主题；面板补一圈边框。
- 不用渐变、高饱和色、霓虹色。

### 间距

| 令牌 | 值 | 常见用途 |
| --- | --- | --- |
| `space1` | 4 | 标题与说明之间、键帽内边距 |
| `space2` | 8 | 控件之间、页面列中相邻块之间、无标题分组前 |
| `space3` | 12 | 分组标题与面板之间、表单字段之间、子项行上下内边距 |
| `space4` | 16 | 一级设置行上下内边距、行内文字与控件之间 |
| `space5` / `rowInset` | 20 | 面板左右内边距；面板外的标题和说明也缩进 20，与面板内文字对齐（项目约定） |
| `space6` / `subIndent` | 24 | 有标题分组前的外边距（加上列间距共 32）、每级子项缩进 |
| `space10` | 40 | 内容区左右边距、导航项最小高度 |
| `space12` | 48 | 内容区底部留白 |

- 只用 4 的倍数。例外仅限「锁定界面」和图形内部（色卡示意、键盘热度图键帽、图表柱），这些是画出来的图形，不是布局间距。
- 一级设置行最小高 64（`rowMinHeight`），子项行最小高 52（`subRowMin`）。
- 数字输入框统一宽 120；下拉框按内容取 120–280。

### 圆角

| 令牌 | 值 | 用于 |
| --- | --- | --- |
| `controlRadius` | 8 | 按钮、输入框、下拉框、导航项、键帽、色卡、提示底色块 |
| `panelRadius` | 16 | 分组面板、搜索结果面板 |
| mygo 默认 | — | 弹窗、菜单、提示气泡，不改 |

### 字号与字重

| 令牌 | 字号 | 字重 | 颜色 | 用于 |
| --- | --- | --- | --- | --- |
| `fontTitle` | 28 | 600 | 主文字 | 页面标题 |
| `fontHeading` | 17 | 600 | 主文字 | 弹窗标题、状态卡标题、同步时间等单个数值 |
| `fontSection` | 15 | 600 | 主文字 | 分组标题、列表标题 |
| `fontBody` | 14 | 500 / 400 | 主文字 | 一级设置名用 500；子项名和正文用 400 |
| `fontCaption` | 13 | 400 | 次要文字 | 设置说明、面板下说明、空状态、数量 |

- 13 是最小字号，不再用 12、12.5。例外：键盘热度图键帽上的字随图缩放。
- 不用 700 以上的字重。说明文字行高 1.5，标题行高 1.4。
- 所有字号经 `textSize(c, …)` 换算，跟随 Windows 文字大小。

### 动效

- 时长 150–250ms，用 mygo 默认的 ease-out；次要操作淡入淡出用 `revealDuration`（160ms）。
- 不加悬停上浮、放大或阴影；系统要求减少动态效果时由 mygo 直接跳到终态。

## 窗口结构

| 区域 | 规格 |
| --- | --- |
| 标题栏 | 隐藏系统标题栏；顶部一条可拖动区，高度取系统标题栏高度且不低于 32 |
| 侧边栏 | 宽 236；顶部 32 像素品牌图标加「FreeType」（16 / 600），不加副标题；导航项之间 4；底部固定「搜索设置」 |
| 内容区 | 左右各 40，顶部 8，底部 48；内容列最大宽 860，宽窗口两侧留空相等；列内相邻块间距 8 |
| 最小窗口 | 780 × 540，文字放大 150% 时也不得横向溢出 |

## 组件

所有组件在 `widgets.go`，页面代码只组合它们。

- **页面标题** `pageHeader(title, note)`：`note` 只写使用前提、限制或隐私范围（如输入统计「只在这台电脑保存」），没有就留空。
- **分组** `section(title, fn)`：分组标题（可为空）加一块面板；面板内每项之间一条 1 像素细线，首尾不加线。
- **面板** `panel()`：白底（深色为浅一级的灰），圆角 16，无边框、无阴影。不嵌套。
- **设置行** `row` / `switchLine` / `choose`：左边名称与说明，右边控件；放不下时控件整组换到下一行，不缩小文字。开关旁不写「开 / 关」。点名称也能切换开关。
- **子项** `settingGroup` + `subGroup` / `nestedSubGroup`：父项展开的从属设置每级缩进 24；子项之间和子项区顶部各一条细线，细线从缩进处开始。不画底色框或侧边条。
- **表单区** `subContent`：子项里的输入框、勾选网格，上下各 12。
- **列表**：多条同类记录（学到的词、快捷短语、常用语、词库词条、软件规则）放进一块面板。批量操作（全选当前结果、删除选中）放在面板顶部一行。单条删除等次要操作用 `onIntent` 平时隐藏，指针悬停或键盘焦点进入该行时淡入；隐藏时仍可用 Tab 聚焦。
- **列表标题** `listHeader(title, controls)`：在面板上方，左边标题加条数，右边搜索框或刷新按钮。
- **说明** `hint`（面板下）和 `caption`（面板内）：13 号次要文字，与面板内文字左对齐。
- **状态与故障提示**：用文字或图标表示状态；需要醒目时用一块 `subtle` 浅底色（圆角 8），其中的确认步骤用细线隔开，不再套框。
- **键帽** `keyCap`：13 / 500，`subtle` 底加 `border` 边，圆角 8。
- **搜索结果**：全部结果放一块面板，用细线分隔；每条是可聚焦的按钮行，标题后跟「页面 · 分组」。
- **弹窗**：使用 mygo 的 `Modal` / `AlertDialog`；标题 17 / 600，正文次要文字，按钮右对齐，确认在最右。弹窗内分组靠留白，不加底色框。
- **候选窗预览**：模仿真实候选窗，窗口圆角 8（Windows 11 `DWMWCP_ROUND`）、选中底色块圆角 4（`paint.rs`），不套用设置页令牌（`previewWindowRadius`、`previewItemRadius`）；预览窗保留一层淡阴影，模仿系统投影。预览舞台本身是一块普通面板。

## 文案

- 用户可见名称统一为 FreeType。用常用词、短句和明确动作；末尾不加标点，句间用「；」；保留默认值、条件与限制。代码、路径、版本号、按键与符号示例不改。
- 设置说明集中在 `windows/app/search.go` 的 `settingsItems`，名称、说明和搜索关键词共用一份。说明只复述标题时删去说明，把检索词移到关键词。
- 不写页面副标题、标语和「点此可以……」式引导。

## 验收

改动界面后按顺序执行：

1. 运行设置界面测试，并导出离屏截图（不打开真实窗口，不接触当前桌面）：

   ```powershell
   $env:FREETYPE_SNAPSHOT_DIR = "$PWD\_temp\<任务>\shots"
   $env:FREETYPE_UI_RESOURCES = "$PWD\windows\app\resources"
   cd windows\app; ..\..\.local\toolchains\go1.27.4\bin\go.exe test -count=1 .
   ```

   `TestSettingsPageLayoutMatrix` 为每页输出浅色、深色、正常、最小窗口、150% 文字、125% 缩放和 125% DPI 共 10 张截图；其他测试输出弹窗、搜索、同步故障和统计等状态。
2. 逐张查看真实截图，核对：
   - 页面标题、分组标题、设置名、说明的左边缘：分组标题、列表标题、面板下说明与面板内文字对齐；
   - 右侧控件在同一面板内右对齐，最小窗口和放大文字时不越界、不截字；
   - 面板没有阴影，面板里没有带底色或边框的嵌套框；
   - 粉色只出现在开关、勾选、主按钮、统计数据和品牌图标上；
   - 列表的单条删除平时隐藏，悬停时出现；
   - 深色和高对比度下文字清楚可读。
3. `design_test.go` 覆盖可自动判断的两条：列表次要操作的隐藏、显示与键盘可达，以及面板内外文字左对齐。新增约定能自动判断时补进该文件。
