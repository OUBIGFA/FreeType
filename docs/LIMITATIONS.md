# 目前做不到的

本页说明 FreeType Windows 版的实际边界。保留的 Linux/macOS 源码属于上游移植参考，不表示 FreeType 提供对应平台的安装包。

- 支持 Windows 10/11 x64；安装包含 x86 输入法组件，供 32 位应用使用，不支持纯 32 位 Windows。
- 语音输入和互译尚未接入 Windows 界面。
- 生僻字和新表情的显示取决于系统字体是否包含对应字形。
- 候选排序结合词频、随包词级语言模型和个人学习，不能保证首次使用就正确区分全部同音词。
- 大型词库导入、备份恢复仍需要读取和校验数据；处理期间可能短暂影响输入。可在暂不输入时执行这些操作。
- 安装器目前未签名。覆盖较早版本后，尚不支持组件交接的旧应用进程需要关闭并重新打开；支持交接的组件在停止组字后加载新版本。

具体功能与验证范围见 [Windows 说明](WINDOWS.md) 和 [行为对应表](WINDOWS-PARITY.md)。
